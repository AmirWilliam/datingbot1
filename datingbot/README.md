# ربات دوست‌یابی دانشجویی پیشرفته

## ویژگی‌ها

- **ثبت‌نام کامل** بدون پرسیدن شهر
  - اسم (مثلاً امیر یا مینا)
  - جنسیت
  - دنبال چه کسی (مرد / زن / هر دو)
  - مقطع تحصیلی (کاردانی / کارشناسی / ارشد / دکتری)
  - ترم
  - سن
  - علایق (چند انتخابی)
  - بیو
  - عکس پروفایل (**اجباری**)

- **سیستم مچینگ**
  - نمایش پروفایل‌های مناسب بر اساس فیلتر جنسیت
  - لایک / بعدی / بلاک / گزارش
  - مچ متقابل با اطلاع‌رسانی
  - وقتی کسی لایکت کنه بهت پیام میاد («فلانی شما را لایک کرد») با دکمه‌های **لایک کردن** و **مشاهده پروفایل**

- **چت دوطرفه داخل ربات**
  - بعد از مچ، از «مچ‌های من» روی «شروع چت» بزنید؛ برای طرف مقابل پیام می‌رود («می‌خواد باهاتون چت کنه، قبول می‌کنی؟») با دکمه‌های **آره / نه**
  - فقط بعد از قبول کردن، چت (متن، عکس، ویس) باز می‌شود
  - خروج با `/stopchat`

- **درخواست آیدی با اجازه**
  - کاربر درخواست می‌دهد → طرف مقابل پیام دریافت می‌کند:
    > «امیر می‌خواد آیدی‌ت رو بدونه، اجازه می‌دی؟»
  - فقط در صورت تأیید، آیدی ارسال می‌شود

- **منوها**
  - پیدا کردن دوست
  - مچ‌های من
  - پروفایل من
  - ویرایش پروفایل (بیو، عکس، علایق، ...)
  - تنظیمات (فعال/غیرفعال کردن پروفایل، حذف حساب)
  - راهنما

- **گزارش تخلف**
  - کاربر با دکمه «⚠️ گزارش» دلیل را انتخاب می‌کند (یا خودش می‌نویسد)
  - گزارش با دلیل، آیدی گزارش‌دهنده و گزارش‌شده برای مالک ارسال می‌شود
  - مالک می‌تواند گزارش را **تأیید**، **تأیید + مسدود** یا **رد** کند و نتیجه خودکار برای گزارش‌دهنده می‌رود
  - مالک با دکمه «📜 سابقه چت» چت دو طرف را می‌خواند

- **پنل مالک** (فقط ادمین‌ها)
  - دکمه «🛠 پنل مالک» در منوی پایین (فقط برای ادمین) یا `/admin`: آمار، پیام همگانی، غیرفعال/فعال کردن ربات برای عموم، لیست کاربران با تاریخ ثبت‌نام (شمسی)، گزارش‌های در انتظار
  - `/myid` آیدی عددی خودت را نشان می‌دهد (برای قرار دادن در `ADMIN_IDS`)
  - `/reports` گزارش‌های در انتظار
  - `/chats آیدی` لیست چت‌های یک کاربر، `/chatlog آیدی1 آیدی2` سابقه چت دو نفر
  - `/ban آیدی` و `/unban آیدی`

## نصب و اجرا

```bash
pip install -r requirements.txt
```

توکن ربات را در خط بالای `bot.py` قرار دهید:

```python
TELEGRAM_TOKEN = "123456:ABC-DEF..."
```

در صورت نیاز آیدی عددی ادمین‌ها را هم اضافه کنید:

```python
ADMIN_IDS = [123456789]
```

سپس اجرا کنید:

```bash
python bot.py
```

## نکات

- دیتابیس SQLite به صورت خودکار ساخته می‌شود (`dating_bot.db`)
- برای استفاده روی سرور می‌توانید از systemd یا screen استفاده کنید
- ربات کاملاً فارسی است
- پیام‌های چت در دیتابیس ذخیره می‌شوند (جدول `chat_log`)؛ کاربران در راهنما و هنگام شروع چت از این موضوع مطلع می‌شوند
